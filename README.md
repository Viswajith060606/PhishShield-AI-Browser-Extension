# PhishShield-AI-Browser-Extension
A 100% standalone, privacy-first Chrome extension that detects real-time zero-day phishing and web fraud. Built with Manifest V3, PhishShield AI combines sub-2ms local Sigmoid ML scoring, visual homoglyph analysis, form interception, and Google Gemini 3.6 Multimodal Vision to stop credential harvesting right inside the browser.

Sub-2ms Local Latency: Instant heuristic & Sigmoid probability scoring on the client side.

Privacy-First Architecture: No tracking proxies; browsing data never leaves your device.

Multimodal AI Audits: Triggers Gemini 3.6 Flash Vision to spot pixel-perfect visual login clones.

Dynamic Form Interceptor: Halts unauthorized cross-origin credential submissions before data transmits.

RDAP Domain Intel: Evaluates domain age to penalize Newly Registered Domains (NRDs).
